# Floratype 🌸

> **Type, and a garden grows from your letters.**  
> Space cuts the stems, backspace withers them.

Floratype is an interactive generative typography experiment where organic stems, leafy vines, and blooming roses branch dynamically out of typography as you type in real-time.

---

## ✨ Features

- **Kinetic Botanical Growth**: High-DPI canvas procedural rendering with line-boil dynamics, sinusoidal harmonics, and spring-recoil velocity physics.
- **Micro-Interactions & Physics**: Roses lean toward cursor/touch points, stems blossom with keystrokes, spaces slice vines, and backspaces wither petals smoothly.
- **Dual Modes**:
  - **Type Mode**: Minimalist immersive canvas with responsive typography and adaptive soft keyboard support.
  - **Poster Mode**: Real-time editorial design studio featuring custom palettes (*Rose Noir*, *Gardenia*, *Marigold*, *Hydrangea*), recoil controls, boiling toggles, and vector exports.
- **High-Fidelity Typography**: Variable OpenType `GT Ultra`, `DM Mono`, and `Playfair Display`.
- **Zero-Latency Mobile & Touch**: Full mobile optimization with `visualViewport` responsive adaptation for iOS Safari and Android virtual keyboards.
- **Export Options**: One-click download as high-res PNG or scalable SVG.

---

## 🚀 Quick Start

Run Floratype locally with Node.js:

```bash
# Start local server
node server.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack

- **Graphics**: Hardware-accelerated HTML5 Canvas 2D & WebGL shaders
- **Animation**: Physics-based procedural curve engines & `requestAnimationFrame`
- **Runtime**: Self-contained reactive virtual DOM engine
- **Typography**: `GT Ultra`, `Playfair Display`, `DM Mono`
